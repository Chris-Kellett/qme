# Discord Bot Template
This is a basic project template to be used for Discord bots.

It includes the following packages, with basic tests provided:
- Bot
- Config
- Database
- Handlers
- Logger
- Ping

The .env file below can be used, make sure to replace the X values as they are required:
```
APPISDEV=true
DISCORDBOTTOKEN=X
DB_NAME=X
DB_USER=X
DB_PASSWORD=X
DB_IP_ADDRESS=X
DB_PORT=X
LOGGINGUSESTHREADS=false
LOGVERBOSESTACK=false
LOGFUNCTIONS=false
```
